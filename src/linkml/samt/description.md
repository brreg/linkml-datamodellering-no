SAMT-domenet (Samarbeid om Modernisering av Tenesteforvalting) inneheld tverrgåande samhandlingsmodellar for kommunesektoren. `samt-bu` dekkjer barn og unge-relaterte tenester, inkludert skuleinformasjon, elevdata og organisasjonsstruktur for samarbeidande kommunar.

**Typisk brukar:** Kommunale og offentlege verksemder som samarbeider om modernisering av tenester for barn og unge, og utviklarar som implementerer tverrgåande integrasjonar.
