FAIR-domenet inneheld éin metadatamodell, `fair-metadata`, som utfyllar dei norske applikasjonsprofilane (DCAT-AP-NO, SKOS-AP-NO m.fl.) med tilleggseigenskapar for [FAIR-prinsippa](https://www.go-fair.org/fair-principles/) (Findable, Accessible, Interoperable, Reusable).

Modellen er, som AP-NO-profilane, meint for import inn i domenemodellar — han har inga eiga `tree_root`-klasse.

**Typisk brukar:** Forskingsinstitusjonar og offentlege verksemder som skal publisere FAIR-konforme datasett, og modellerarar som ønskjer å utvide eigne domenemodellar med FAIR-metadata.
