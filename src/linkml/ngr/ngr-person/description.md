LinkML-modell av Nasjonale grunndata - Person, modellert som ein domenemodell for norsk personinformasjon.

Modellen dekkjer persondata frå Folkeregisteret, inkludert navn, identifikatorar, fødselsdato, kjønn og sivilstand.

**Typisk brukar:** Offentlege verksemder som arbeider med persondata frå Skatteetaten sitt Folkeregister, og utviklarar som implementerer person-API-ar baserte på Nasjonale grunndata.
