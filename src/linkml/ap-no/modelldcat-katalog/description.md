`modelldcat-katalog` inneheld katalogklassane frå ModelDCAT-AP-NO: `Modellkatalog`, `Informasjonsmodell` og modelldcat-spesifikke hjelpeklasser (`Lisensdokument`, `Dokument`). Klasser som er felles med DCAT-AP-NO (`Aktoer`, `Kontaktopplysning`, `Standard`, `Tidsrom`, `KatalogisertRessurs`) er arva via import av `dcat-ap-no`.

Skjemaet vart delt ut frå [`modelldcat-ap-no`](../modelldcat-ap-no/index.md) som eigen del av spesifikasjonen ([katalogdelen](https://data.norge.no/specification/modelldcat-ap-no#Egenskaper-katalogdel)), og importerer sjølv [`modelldcat-modell`](../modelldcat-modell/index.md).

**Avvik frå spesifikasjonen:** Sjå `specs/done/avvik-modelldcat-ap-no.md` for dokumenterte avvik og grunngjevingar.
