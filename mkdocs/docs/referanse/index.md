# REFERANSE - Referansemodellar

Referansedomenet inneheld `referansemodell`, eit undervisningsskjema som demonstrerer alle hovudmønster brukte i dette repoet: containerklasse, globale slots, import-hierarki, URI-mapping, fleirspråklege strengar, obligatorisk/anbefalt/valgfri-klassifisering og lenking framfor inlining.

Skjemaet finst òg i medaljong-variantar (`referansemodell-bronze`, `-silver`, `-gold`) som illustrerer kva som krevst på kvart policy-nivå — sjå policy-hierarkiet i CLAUDE.md.

**Typisk brukar:** Nye utviklarar som lærer LinkML-modellering i dette repoet. Skjemaet vert ikkje brukt i produksjon.
