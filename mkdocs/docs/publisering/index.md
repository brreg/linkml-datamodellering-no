# Publisering

!!! note "Beskrivelse"

    Denne sida gir oversikt over publiseringsflyten frå repoet til eksterne
    katalogar — kva som vert publisert kor, og korleis Felles Begrepskatalog og
    Felles Datakatalog kan konfigurerast til å hauste frå repoet.

| Side | Innhald |
|---|---|
| [Publiseringsflyt](publisering-oversikt.md) | "Pull, ikkje push"-prinsippet, kvar genererte filer endar (GitHub Pages, Releases, GHCR, raw.githubusercontent.com), og korleis nasjonale katalogar haustar derifrå. |
| [Publiser til Felles Begrepskatalog](publisering-begrep.md) | Korleis begrepsdefinisjonar vert konverterte til SKOS/Turtle og tilrettelagt for hausting til Felles Begrepskatalog. |
| [Publiser til Felles Datakatalog](publisering-modell.md) | Korleis informasjonsmodellar vert skildra i ModelDCAT-AP-NO-format og tilrettelagt for hausting til Felles Datakatalog. |
